### About This Project
I built this portfolio using Next.js and TailwindCSS, focusing on a clean, responsive, and minimalist design. It serves as a space to document my journey as a developer, highlighting my progress through university and my ongoing projects.

### Tech Stack
-Framework: Next.js
-Styling: TailwindCSS
-Deployment: Vercel (or Netlify)

### Features
-Responsive Layout: Designed to look great on mobile, tablet, and desktop.
-Project Showcase: Organized view of my work by year.
-Resume Integration: Dedicated section to view my professional experience and education.
-Easy Customization: Built with a modular structure for easy updates.

### Getting Started
To run this project locally, follow these steps:

1. Clone the repository:
```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
```
2. Install dependencies:
```bash
npm install
```
3. Run the development server:
```bash
npm run dev
```
4. Open http://localhost:3000 on browser to see the result.

### Deployment
I recommend deploying this project via Vercel or Netlify for the fastest performance and automatic deployments when you push code to GitHub.
